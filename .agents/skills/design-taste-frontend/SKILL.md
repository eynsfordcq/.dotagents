# Frontend design

Use this skill for landing pages, portfolios, and marketing pages. Read the brief and inspect any existing site. Infer the audience, content, brand, and degree of change. Let the user and the project's existing design rules decide the direction.

Read only the reference that helps the current task:

- [Visual direction](references/visual-direction.md): composition, type, color, layout, images, and design-system choice.
- [Motion and accessibility](references/motion-and-accessibility.md): animation patterns, reduced motion, theme, and performance. Read when motion or theme work is involved.
- [Patterns and copy](references/patterns-and-copy.md): examples of common visual cliches and possible alternatives. Consult when exploring a layout or editing page copy.
- [Redesign and verification](references/redesign-and-verification.md): audit and preservation guidance for an existing site, plus a detailed visual checklist. Read for redesigns or substantial new pages.
- [Design-system sources](references/design-system-sources.md): package commands and official sources. Read only when selecting or installing a system.

The references contain examples and strong opinions, not universal requirements. Apply only what fits the brief. Preserve existing product behavior and content unless the user asks to change them. Inspect the rendered page at relevant viewport sizes and fix visible problems before finishing.
